# d3studio — студия ассетов (полный режим)

Локальная студия для ассетов Disciples 3: концепт на своей видеокарте → 3D-модель → glTF →
**файлы игры** (`.g`, `.scene`, `.ac`, `.a`, `.t`) через `d3tool` из этого же репозитория.

## Откуда взялось

Основа — релиз **AstraForge 0.3.0** (MIT, `github.com/Snodrod/AstraForge`, тег `v0.3.0`):
сервер на Express, интерфейс на React, конвейер 3D (Hunyuan3D/Pixal3D через ComfyUI, мосты в
Blender и Godot). Лицензия MIT разрешает брать код за основу и переделывать его под себя при
условии сохранения уведомления об авторских правах — оно лежит рядом в `LICENSE` и
`THIRD_PARTY_NOTICES.md`, а исходные документы базовой версии — в `docs/base/`.

Что мы переделываем (и почему):

| Что | Как было | Как у нас |
|---|---|---|
| Назначение | Godot-пакеты, спрайты, эффекты | **родной формат Disciples 3** через `d3tool` |
| Экспорт | `.glb` / Godot-пакет | `POST /api/d3/export` → `.g/.scene/.ac/.a` (`server/d3tool.mjs`) |
| Имя, версия, подпись | AstraForge 0.3 | d3studio 0.3.1 |
| Запуск | `Start.cmd` их установщика | любой Node ≥ 20, см. ниже |

## Запуск

```bash
npm ci                      # один раз: 111 пакетов
npm start                   # http://127.0.0.1:3210
npm run dev                 # то же, но с горячей перезагрузкой интерфейса
npm test                    # node --test tests/*.test.mjs
```

Студия слушает только `127.0.0.1` и отказывает запросам с чужим `Host`/`Origin` — так было в
базовой версии, и это правильно для приложения без паролей.

Для экспорта в игру нужен Python с этим репозиторием и переменные окружения:

```bash
set D3TOOL_PYTHON=python            # как называется python на машине
set D3TOOL_REPO=D:\geo2011          # где лежит пакет d3tool
```

`POST /api/d3/export {"assetId": "…"}` возвращает список файлов и ссылки на них; файлы пишутся в
`data/d3exports/<id>/`, метаданные — рядом. Ошибки (нет Python, ненулевой код, пустой экспорт)
приходят текстом, а не «ошибка 500».

## Что ещё не переписано

Базовая версия велика: ~7 200 строк сервера и ~13 500 строк интерфейса. В этом заходе сделано
только самое нужное — своё имя, свой экспорт в игру и тесты к нему; остальное лежит как есть и
переделывается по мере надобности:

* брендинг внутри i18n (`src/i18n/*.json`), заголовок окна помощи, `x-astra-client` в запросах;
* установщик (`installer/`, `ai/skills`, `data/runtime/custom_nodes`) — материал базовой версии,
  студия работает и без него, если ComfyUI и модели уже стоят;
* Godot/Unity-экспорт, VFX, спрайты — пока не наши цели (см. `docs/studio/PLAN.md`).

# Своя студия на базе AstraForge 0.3.0 (MIT)

Это форк **AstraForge 0.3.0** — последней версии под MIT. Здесь можно править
что угодно и в любых целях, включая коммерческие: MIT разрешает всё, кроме
удаления уведомления об авторстве. Подробности и границы — в `NOTICE.md`.

## Почему именно 0.3.0

| | 0.3.0 (MIT) | 0.6.12 (PolyForm NC) |
|---|---|---|
| лицензия на код | MIT: меняй, продавай, закрывай | некоммерческая, коммерческое использование нельзя |
| проверка подписки | **нет** | ключ Lemon Squeezy / AF-… |
| телеметрия | **нет** | отчёты + журнал обучения |
| автообновление | **нет** | тянет релизы с GitHub |
| собственный движок (engine/) | нет — работает через ComfyUI | да, :8192 |
| Hunyuan3D, звук, скульпт, 2D-вкладка | нет | да |
| ракурсы (MV-Adapter), 3D (Tripo, Pixal3D), Кузница, UV, VFX | **есть** | есть |

То есть в 0.3.0 нет ничего, что нужно было бы «снимать»: ни проверок, ни отправки
данных, ни автообновления — оно не утащит форк обратно в платную 0.6.x.

## Что здесь уже сделано нами

1. **Pascal (GTX 10xx/16xx).** `installer/Install.ps1`: индекс PyTorch выбирается
   по compute capability карты (`cu126` для sm_61 вместо `cu128`), а `torch`
   переставляется, если в сборке нет `sm_61` — импорт на Pascal проходит, но любой
   kernel падает с «no kernel image is available».
2. **Память перед «Ракурсами».** `server/views.mjs`: перед стартом генерации
   студия спрашивает `/system_stats` у ComfyUI и, если свободной памяти меньше
   нужного, отвечает 409 с цифрами вместо падения внутри ComfyUI через секунду
   («os error 1455»).

## Установка

```
Install AstraForge.cmd     — установщик (Windows, нужен Node.js 22.12+)
Start.cmd                  — запуск
Stop.cmd                   — остановка
```

Установщик сам поставит ComfyUI, Python 3.12 и библиотеки. Патч Pascal уже внутри,
так что на 1080 Ti выбирается cu126.

## Как добавлять «обновления» из новых версий

Только переписыванием. Код 0.4.2+ под PolyForm Noncommercial: один перенесённый
файл — и весь форк перестаёт быть MIT. Смотрим, как это устроено, и пишем своё:
другой код, свой стиль, свои имена.

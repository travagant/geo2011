# Правка памяти для студии AstraForge 0.6.12

Отдельно от моста: мост (`D:\geo2011`) разговаривает со студией, а этот пакет
меняет саму студию. Ставится один раз, откатывается одной командой.

## Что исправляет

Всё про одно: Windows отказывает в памяти с «файл подкачки слишком мал
(os error 1455)», когда RAM ещё показывает свободные гигабайты. Пять правок:

| файл | что было | что стало |
|---|---|---|
| `engine/astra_engine/device.py` | ошибка 1455 говорила «закройте ComfyUI, Ollama, игры» — без цифр | тот же текст плюс замер: RAM, файл подкачки, свободно памяти |
| `engine/astra_engine/engine.py` | `keep_ram()` решал по объёму RAM: на 32 ГБ веса SDXL+MV-Adapter (10 ГБ) оставались в RAM после задачи | оставляет их, только если свободный commit ≥ 12 ГБ |
| `engine/astra_engine/server.py` | `/system_stats` отдавал `ram_free`, но не commit | плюс `commit_free` и `commit_limit` |
| `server/views.mjs` | «Ракурсы» стартовали и падали внутри движка через секунду | проверяют память до старта, 409 с нехваткой в гигабайтах |
| `server/runtime.mjs` | `--lowvram --reserve-vram 1` намертво | то же по умолчанию, но `ASTRA_COMFY_LOWVRAM=0` (normalvram, резерв 0.5) или `=auto` (lowvram, резерв 0.5) |

Правки идемпотентны: второй запуск пишет «уже исправлено». Первое изменение файла
делает копию `.bak` рядом с ним.

## Установка

1. **Распакуй архив в отдельную папку**, не в студию и не в мост. Например
   `D:\astraforge-memory-patch`.
2. **Закрой студию.** Проверь, что нет `AstraForge` в трее и в диспетчере задач:
   файлы `server\views.mjs` и `server\runtime.mjs` читаются при старте сервера.
3. Двойной клик: **`Apply-memory-patch.cmd`**.
   Он сам найдёт студию на C:/D:/E:/F:, возьмёт python из `py`/`python`/venv
   движка и покажет по каждой правке «исправлено» или «пропущено».
4. **Запусти студию** и попробуй «Ракурсы».

Ожидаемый вывод в конце:

```
итого: исправлено 9 (изменено файлов 5), пропущено 0
```

## Если что-то пошло не так

**Посмотреть, что изменится, ничего не меняя:**

```
Apply-memory-patch.cmd --check
```

**Откат** (вернёт все пять файлов из `.bak` и удалит копии):

```
Apply-memory-patch.cmd --revert
```

**«пропущено (нет такой строки — другая версия студии)»** — нормально, если у
тебя не 0.6.12. Файл при этом не тронут: патч не пытается угадать. Пришли вывод
скрипта — добавлю якоря под твою версию.

**Студия не найдена.** Укажи папку вручную:

```
Apply-memory-patch.cmd --studio E:\AstraForge
```

## Что это НЕ исправляет

Память компьютера эта правка не добавляет. Если 1455 уже случился, причина в
балансе RAM + файл подкачки; цифры теперь печатает сама студия, а посчитать и
поднять подкачку умеет `RAM-check.cmd` из сборки моста 24.

С `ASTRA_COMFY_LOWVRAM=0` на 11 ГБ видеопамяти SDXL живёт в VRAM и не гоняется
через RAM, но на 832 px и выше возможен OOM. По умолчанию режим не меняется.

## Проверено

17 тестов на синтетических копиях файлов 0.6.12: применение всех девяти правок,
идемпотентность, откат, сохранение CRLF и BOM, отказ при чужом якоре.
Пропатченные файлы прогнаны через `node --check` и `py_compile`.

## Отчёты и журнал обучения (отдельный файл)

`Telemetry-off.cmd` выключает то, что студия отправляет автору: отчёты об ошибках и
журнал «Кузницы»/«Приёмки» (какие шаги, параметры, вердикты, теги брака). Это
документированный выключатель из `PRIVACY.md` — «О программе → Отчёты и обучение», просто
без мышки: `PUT /api/telemetry {errors:false, learning:false}`.

```
Telemetry-off.cmd            выключить оба
Telemetry-off.cmd --check    только показать состояние
Telemetry-off.cmd --on       включить обратно
```

Студия должна быть запущена — это вызов её собственного API, перезапуск не нужен.
Проверка обновлений при этом остаётся: она не телеметрия, а обновления.

## Чего этот пакет не делает

Не снимает проверку подписки, не подделывает ключи, не обходит owner-mode и подпись
релизов. Лицензия 0.6.12 — PolyForm Noncommercial 1.0.0: менять код для личных и
некоммерческих целей она разрешает, но коммерческое использование запрещает и требует
сохранять уведомление об авторстве. Снятая проверка подписки не добавляет ни одной
функции (без подписки студия и так работает целиком — не приходят только обновления),
зато делает любую «свою студию» на этом коде юридически непригодной для распространения.

# Лимиты Zen «из коробки»: что поднимается, а что нет

Короткий ответ: **в конфиге поднимается, в реальности — нет.** Лимит Zen — это лимит
аккаунта, а не поле в `opencode.json`. Путать эти две вещи дорого: поднять цифру в
файле можно, но запросы всё равно упрутся в сервер.

## Два разных лимита

| Лимит | Где живёт | Поднимается |
|---|---|---|
| `limit.context` / `limit.output` | `opencode.json`, локально | да, правится в блоке модели |
| Квота аккаунта (запросы/токены) | сервер OpenCode | **нет**, только деньги/подписка |
| `100 запросов в день` (LongCat 2.5 Free) | сервер провайдера | нет, жёстко |
| Rate limit в минуту | сервер | нет, нужен другой пул |

То есть «лимит из коробки» из меню `Default/None/Low/High/Max` — это **reasoning
effort**, не квота. Он вообще ничего не поднимает, только меняет глубину рассуждений.

## Что реально даёт больше Zen

| Путь | Что даёт | Цена |
|---|---|---|
| **`/connect` → OpenCode Zen, затем платежные данные** | платные модели по запросу: GPT, Claude, Gemini, GLM | за запрос |
| **OpenCode Go** (подписка) | пакет usage на модели OpenCode | подписка |
| **budgets / auto-recharge** | автоматическое пополнение и лимит месяца | деньги |
| **`opencode auth login` + ключ** | просто доступ, квоты не меняет | бесплатно |

Кнопки «увеличить free-квоту» в Zen нет. Free-модели выдаются «на ограниченное
время» и с общим лимитом аккаунта — это промо, а не тариф.

## Что поднимается в конфиге

Только то, что относится к твоему клиенту:

```json
"opencode": {
  "name": "OpenCode Zen",
  "models": {
    "deepseek-v4.1-flash-free": {
      "limit": { "context": 131072, "output": 16384 }
    }
  }
}
```

Эта цифра — **порог сжатия** и потолок ответа, а не квота. Хочешь вернуть 200k —
поменяй на `200000`. Квоту это не увеличит, только даст больше контекста за ход
(и прогон станет дороже в пересчёте на запросы).

## Что это значит на практике

Единственный честный способ «поднять лимит» — **добавить пул**, а не поднять цифру:

1. Coarena — 30 запросов в минуту, сброс в 00:00 UTC
2. Zro — дневная free-квота, сброс каждый день
3. Zen — общий лимит аккаунта, free на ограниченное время

Три пула с независимыми лимитами дают втрое больше прогонов, чем один пул с
поднятым `context`. Поэтому в финальном конфиге они и стоят рядом.

## Полезная деталь про сам OpenCode

`OPENCODE_DISABLE_FREE_MODELS=1` **скрывает** free-модели из каталога. Обратное
не работает: переменной «включить больше free» не существует.

## Вывод

- Поднять в файле — можно (`limit.context`).
- Поднять на сервере — нельзя, только деньгами или подпиской.
- Больше бесплатных прогонов даёт **не больший лимит, а другой пул**.
- `Default/None/Low/High/Max` — это reasoning effort, к квоте отношения не имеет.
